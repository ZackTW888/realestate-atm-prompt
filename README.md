# AI 房仲指令工坊

1119 桃園不動產仲介課程的 ATM（A 角色／T 目標／M 方法）指令教學網站。單一靜態 `index.html`，可直接部署到 Vercel（Framework: Other）。

- ATM 架構：無效指令 vs 有效指令，課堂三個房仲範例（平鎮宜居、長庚養生村、青年招募見證文案）。
- 文案指令產生器：6 個房仲情境 → A／T／M 點選，即時組出指令與建議追問，附刊登前檢查。
- 圖像指令產生器：網站上架宣傳圖、模特代言推廣圖、社群經營乾貨圖、自媒體企劃封面圖；比例、風格、色碼，產出一句話短指令與 ATM 完整指令，附版面示意。
- 猜猜關鍵字：三張課堂成品圖的指令關鍵字小遊戲。
- 繪圖練習：練習 2 計時器、ChatGPT image 2 綜整、工具連結。
- 心得與收穫：三題分享稿。
